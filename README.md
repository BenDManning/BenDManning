# Ben Manning

I build, repair, and customize the systems I use, from Linux desktop tools to the electronics and mechanics of a 350 mm Voron printer. These projects document the problems I encounter, the changes I make, and what I learn along the way.

## Featured projects

### [Omarchy customizations](https://github.com/BenDManning/omarchy-customizations)

Touchscreen screenshot selection and automatic night-light control for my Linux laptop. Includes a focused patch to `slurp`, a Python service, a QML control widget, and installation scripts.

I wanted to tap a window or drag a screenshot region with my finger, and have the display adjust its warmth around sunrise and sunset.

### [Voron 2.4 build and rebuild](https://github.com/BenDManning/Voron2.4)

My 350 mm Voron 2.4r2: CAN-connected electronics, eddy-current probing, hardware repairs, and mechanical and thermal improvements. The build notes explain what's installed, what I've changed, and what's going into the rebuild.

**In progress:** hardware documentation and the upgrade roadmap are available now. Configuration files and photos will follow when I'm back at the printer.
